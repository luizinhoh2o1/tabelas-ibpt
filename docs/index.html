Compressão Gzip

Dados comprimidos com gzip nível 9. De ~4,5 GB de CSV bruto para ~542 MB (88% de redução). Descompressão automática no navegador.

100% Client-Side

Sem backend. Os dados são buscados, descomprimidos e filtrados diretamente no navegador via DecompressionStream.

Todas as Versões

100 tabelas de 2015 a 2026, 32.652.402 registros. Todos os semestres e revisões (A, B, C…) disponíveis para consulta histórica.

Consultar sem filtros carrega todos os registros de uma vez, o que pode consumir toda a memória do navegador e fazer a página parar de responder. Use pelo menos um filtro para refinar a busca.

Endpoints da API

Base URL:

Arquivos de dados usam extensão .json.gz (gzip). Índices usam .json (sem compressão).

  • GET
    /api/meta.json
    Metadados: anos disponíveis, versões/tabelas, tipos e UFs.
  • GET
    /api/{ano}/index.json
    Índice do ano com todas as versões. Ex: /api/2026/index.json
  • GET
    /api/{ano}/{tabela}/index.json
    Índice de uma versão/tabela. Ex: /api/2026/26.1.H/index.json
  • GET
    /api/{ano}/{tabela}/{tipo}/index.json
    Índice por tipo com contagem por UF. Ex: /api/2026/26.1.H/ncm/index.json
  • GET
    /api/{ano}/{tabela}/{tipo}/{uf}.json.gz
    Dados completos (gzip). Ex: /api/2026/26.1.H/ncm/SP.json.gz
  • GET
    /api/todos-{ano}.csv.gz
    CSV consolidado de um ano, com todas as versões, tipos e UFs (gzip). Usado nas consultas amplas. Ex: /api/todos-2026.csv.gz

Descompressão

// JavaScript
const resp = await fetch('/api/2026/26.1.H/ncm/SP.json.gz');
const fluxo = resp.body.pipeThrough(new DecompressionStream('gzip'));
const dados = JSON.parse(await new Response(fluxo).text());
dados.dados.forEach(item =>
  console.log(`${item.codigo}: ${item.aliquotaNacionalFederal}%`)
);
# cURL
curl -s URL/api/2026/26.1.H/ncm/SP.json.gz | gunzip | jq '.dados | length'
# Python
import requests, gzip, json
resp = requests.get('URL/api/2026/26.1.H/nbs/MG.json.gz')
dados = json.loads(gzip.decompress(resp.content))
for item in dados['dados']:
    print(f'{item["codigo"]}: {item["aliquotaNacionalFederal"]}%')

Informações

Como Funciona

  • Construção: Script TypeScript extrai ZIPs, lê CSVs via streaming, agrupa por ano/versão/tipo/UF, gera JSON descritivo e comprime com gzip nível 9.
  • Publicação: GitHub Actions executa o build a cada push e publica no GitHub Pages.
  • Consulta: Página interativa (client-side) ou acesso direto aos endpoints via fetch/cURL/Python.

Compressão

Dados originais: ~4,5 GB de CSV bruto. Após gzip nível 9: ~542 MB (88% de redução) em 7.890 arquivos.

  • Dados: .json.gz (comprimidos)
  • Índices: .json (sem compressão)
  • Browser: DecompressionStream('gzip') - nativo (Chrome 80+, Firefox 113+, Safari 16.4+)

Pesquisa Client-Side

  1. Metadados carregados ao abrir a página (anos, versões, UFs, tipos).
  2. 6 filtros disponíveis: ano, versão, UF, tipo, código e descrição.
  3. Arquivos buscados em lotes paralelos de 8, descomprimidos com DecompressionStream.
  4. Consultas amplas (>50 arquivos) usam os CSVs consolidados por ano (todos-{ano}.csv.gz) via streaming: com filtro de ano, só um arquivo é baixado.
  5. Resultados em tabela com 12 colunas (incluindo vigência), paginados (100/página), ordenáveis, exportáveis como CSV.

Tipos de Dados

  • NCM Nomenclatura Comum do Mercosul - Produtos, 8 dígitos, ~11.000/UF
  • NBS Nomenclatura Brasileira de Serviços - Serviços, 9 dígitos, ~860/UF
  • LC116 Lei Complementar 116 - Serviços municipais, 4 dígitos, ~200/UF
